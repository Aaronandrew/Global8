# global8

Global8 - Global Skater community social app.

Stage 1 Deliverables 
 - Social Media base App design. 
 - User can log in to see the feed of friends they follow. 
 - User has a profile.
 - User can post to the feed with current events or status.
 - User can post pictures/flyers of events or outings.
 - User can add a link to a post. - not yet (instead to profile)
   
Stage 2 Deliverables
 - Map location & Access to event details.
 - Google Maps API - cost$.
 - Map search Skate rinks in the area based on location.
 - Skate rink profiles for upcoming events.
 - Map search to pro shop/ repair shop in area.
 - Map search hotels in the area.

Stage 3 Deliverables
 - Event page based on options.
 - Create Events on the App.
 - Skate Jamz/parties/adult nights/kids night's filter.
 - Chat/Messenger.
 - First 30 days free on App.
